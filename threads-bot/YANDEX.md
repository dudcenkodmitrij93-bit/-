# Бот в Яндекс Облаке

Бот работает как функция в Yandex Cloud Functions. Её запускает таймер 7 раз в день:
08:07, 10:07, 12:07, 14:07, 16:07, 18:07 и 20:07 по Москве. GitHub не нужен.

Номер поста считается по времени запуска (`index.py`), поэтому хранить счётчик не нужно.
Посты идут по кругу. Если запуск пропустится, пропустится и его пост, а следующий выйдет вовремя.

Стоимость: 210 запусков в месяц — это глубоко внутри бесплатного лимита Cloud Functions.

## Настройка

1. **Аккаунт.** Войдите на console.yandex.cloud через Яндекс ID и создайте платёжный аккаунт
   (нужна карта; списаний не будет, пока вы в бесплатном лимите).
2. **Функция.** Cloud Functions → «Создать функцию» → имя `threads-bot`.
3. **Код.** Среда выполнения Python 3.12, способ — «ZIP-архив», загрузите `threads-bot-yandex.zip`
   (внутри `index.py`, `bot.py`, `posts.json`). Точка входа: `index.handler`.
   Таймаут: 120 секунд, память: 128 МБ.
4. **Переменные окружения:** `THREADS_ACCESS_TOKEN` — токен из Meta (Threads API → User Token Generator).
5. **«Сохранить изменения».**
6. **Проверка.** Вкладка «Тестирование», входные данные `{"dry_run": true}` → «Запустить тест».
   Должен показаться текст поста. Без `dry_run` функция опубликует пост по-настоящему.
7. **Таймер.** «Триггеры» → «Создать триггер» → тип «Таймер», cron-выражение
   `7 5,7,9,11,13,15,17 ? * * *` (время в UTC = Москва минус 3 часа), функция `threads-bot`,
   сервисный аккаунт — создать новый с ролью `functions.functionInvoker`.

## Как менять

- **Посты:** поправить `posts.json`, пересобрать архив и загрузить новую версию функции.
  Чтобы новый список начался с первого поста, задайте переменные `START_DATE` (сегодняшняя дата,
  например `2026-11-10`) и `START_INDEX` = `0`.
- **Время:** поменять cron в триггере и список `SLOTS` в `index.py` — они должны совпадать.
- **Токен** живёт 60 дней: сгенерируйте новый в Meta и замените переменную `THREADS_ACCESS_TOKEN`.
