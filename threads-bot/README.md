# Бот для Threads — 7 постов в день

Бот сам публикует посты в Threads 7 раз в день: каждые 2 часа с 08:07 до 20:07 по Москве.
Частоту можно поменять в строке `cron` в `.github/workflows/threads-bot.yml` (время там в UTC, это Москва минус 3 часа).
Он работает через GitHub Actions, поэтому сервер не нужен и это бесплатно.

## Как устроено

- `posts.json` — посты про разработку сайтов. Посты идут по кругу.
  Вместо `{tg}` бот подставляет ссылку на ваш канал, вместо `{bot}` — ссылку на бота с чек-листом
  (константа `TELEGRAM_BOT_URL` в `bot.py`). У поста можно задать свою тему полем `"topic"`.
- `STRATEGY.md` — анализ Threads, целевая аудитория и контент-план.
- `index.py` — запуск по расписанию. Номер поста считается по времени запуска (`START_DATE`,
  `START_INDEX`, `SLOTS`), поэтому бот ничего не коммитит в репозиторий.
- `bot.py` — публикация в Threads, работает без сторонних библиотек.
- `YANDEX.md` — как запустить того же бота в Яндекс Облаке без GitHub.
- `.github/workflows/threads-bot.yml` — расписание.

## Настройка (один раз)

1. **Профиль Threads.** Он должен быть публичным и привязан к Instagram.
2. **Приложение Meta.** Зайдите на https://developers.facebook.com/apps, создайте приложение
   с вариантом использования «Access the Threads API» и включите разрешения
   `threads_basic` и `threads_content_publish`.
3. **Токен.** В разделе Threads API → «User Token Generator» добавьте свой профиль
   как тестировщика (подтвердите приглашение в Threads: Настройки → Ещё настройки → Разрешения сайта → Приглашения)
   и сгенерируйте **долгоживущий** токен (действует 60 дней).
4. **Секрет в GitHub.** В репозитории откройте Settings → Secrets and variables → Actions → New repository secret:
   - `THREADS_ACCESS_TOKEN` — токен из шага 3.

   На соседней вкладке **Variables** создайте переменную:
   - `TELEGRAM_URL` — ссылка на ваш ТГ-канал, например `https://t.me/имя_канала`.
     Можно вместо этого вписать её в константу `TELEGRAM_URL` в `bot.py`.
     Сейчас там уже стоит https://t.me/dudchenko_dmitry.
5. **Ветка по умолчанию.** GitHub запускает расписание только из ветки по умолчанию (`main`),
   поэтому изменения нужно влить в неё.
6. **Проверка.** Actions → Threads bot → Run workflow: бот опубликует пост текущего слота
   (ручной запуск повторит пост, который уже вышел в этот слот).

## Картинки (по желанию)

К посту можно добавить поле `"image": "путь/к/файлу.jpg"` (путь от корня репозитория).
Threads принимает картинку только по публичной ссылке, поэтому репозиторий должен быть публичным,
либо задайте `IMAGE_BASE_URL` с адресом, где лежат картинки.

## Продление токена

Токен живёт 60 дней. Раз в месяц продлевайте его:

```bash
THREADS_ACCESS_TOKEN=старый_токен python threads-bot/bot.py --refresh-token
```

и вставьте новый токен в секрет `THREADS_ACCESS_TOKEN`.

## Как поменять посты или время

- Посты: правьте `posts.json`. Лимит Threads — 500 символов на пост.
  Пути к картинкам указываются от корня репозитория.
- Посмотреть пост текущего слота без публикации: `python threads-bot/index.py --dry-run`.
- Время: строка `cron` в workflow. Она в UTC, поэтому из московского времени нужно вычесть 3 часа.
