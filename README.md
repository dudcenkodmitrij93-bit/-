# Сайт ведущего — Евгений Глуховский

Одностраничный адаптивный сайт по макету `Ведущий/photo_2026-10-20_11-35-28.jpg`.
Чистые HTML/CSS/JS без сборки — можно заливать на любой хостинг как есть.

## Структура

```
index.html        — главная страница
privacy.html      — политика конфиденциальности
css/style.css     — стили (десктоп + планшет + мобильная версия)
js/main.js        — меню, фиксированная шапка, модальные окна, форма, видео
send.php          — обработчик заявок (Telegram и/или e-mail)
img/              — сюда положить фотографии
.htaccess, robots.txt
```

## Фотографии

Положите файлы в папку `img/` с такими именами — они подставятся автоматически
(пока файла нет, показывается аккуратная заглушка с подписью):

| Файл | Где | Рекомендуемый размер |
|---|---|---|
| `hero.jpg` | главный баннер (Евгений справа, тёмный фон) | 2400×1400 |
| `atmosphere.jpg` | карточка «Атмосфера» | 600×600 |
| `video-main.jpg` | превью большого видео | 1300×640 |
| `emotions.jpg` | «Настоящие эмоции. Живые люди.» | 700×420 |
| `v-improv.jpg`, `v-wedding.jpg`, `v-corporate.jpg`, `v-songs.jpg` | превью видео «Посмотрите, как это происходит» | 600×320 |
| `moment-1.jpg` … `moment-4.jpg` | «Моменты, которые хочется пересматривать» (открываются по клику) | 1600×900 |
| `og.jpg` | картинка для превью ссылки в мессенджерах | 1200×630 |

Сжимайте фото (например, на squoosh.app) до 150–400 КБ.

## Видео

У каждого видео-блока в `index.html` есть атрибут `data-video=""`. Вставьте туда ссылку:
YouTube (`https://youtu.be/...`), VK Видео (`https://vk.com/video-123_456`)
или путь к файлу (`video/wedding.mp4`). Пока ссылки нет — открывается окно «Видео скоро появится».

## Заявки с формы

Все кнопки «Обсудить мероприятие», «Подробнее о тарифе», плитки праздников и т.д.
открывают форму. Форма отправляется в `send.php` (нужен хостинг с PHP — это почти любой
обычный хостинг: Beget, Timeweb, REG.RU и т.п.).

Откройте `send.php` и заполните вверху:

- `$TELEGRAM_BOT_TOKEN` — создать бота у [@BotFather](https://t.me/BotFather), скопировать токен;
- `$TELEGRAM_CHAT_ID` — написать боту любое сообщение, свой id узнать у [@userinfobot](https://t.me/userinfobot);
- `$MAIL_TO` — e-mail для дублирования заявок (по желанию).

Достаточно настроить хотя бы один канал. Есть защита от спама (скрытое поле + ограничение частоты).

## Что ещё заменить

## SEO: что уже сделано

- Один `<h1>` на первом экране, у каждого блока свой `<h2>`, у тарифов `<h3>`.
- `title` и `description` с ключевыми словами («ведущий на свадьбу, юбилей, корпоратив»).
- Подробные `alt` у всех фото и обложек видео.
- Open Graph и Twitter-превью (картинка `img/og.jpg` 1200×630) для красивых ссылок в Telegram, ВК, WhatsApp.
- Микроразметка Schema.org (JSON-LD): `Person` (ведущий), `Service` с тарифами и ценами «от», `FAQPage` с вопросами.
- `robots.txt`, `lang="ru"`, сжатые фото, ленивая загрузка картинок, предзагрузка главного фото.

## SEO: что сделать после подключения домена

1. В `index.html` раскомментировать `canonical` и `og:url`, вписать домен; `og:image` заменить на полный адрес `https://ДОМЕН/img/og.jpg`.
2. Создать `sitemap.xml` с адресом сайта и добавить в `robots.txt` строку `Sitemap: https://ДОМЕН/sitemap.xml`.
3. Добавить сайт в Яндекс.Вебмастер и Google Search Console, отправить sitemap.
4. Подключить Яндекс.Метрику (счётчик вставляется перед `</head>`).
5. Создать карточку в Яндекс.Бизнесе / Яндекс.Картах со ссылкой на сайт — важно для поиска «ведущий + город».
6. Вписать город в `title`, `description` и тексты (например, «ведущий на свадьбу в Москве»).

## Страница правок (/admin)

Тексты, цены, сценарии, вопросы, фото и ссылки на соцсети хранятся в `content/content.json`.
Сайт подставляет их при загрузке (`js/content.js`), а менять их можно на странице `ваш-домен.ru/admin`.

**Первый запуск:**
1. В `admin/config.php` замените `ПОМЕНЯЙТЕ-ПАРОЛЬ` на пароль и загрузите сайт на хостинг.
2. Папкам `content/`, `content/backups/` и `img/uploads/` нужны права на запись (обычно 755, на Beget стоят по умолчанию).
3. Зайдите на `/admin`, войдите и сразу смените пароль в разделе «Пароль».

**Что умеет:** менять тексты и цены, добавлять и удалять вопросы, заменять фото (сами уменьшаются),
«Вернуть как было» откатывает последнее сохранение (хранится 30 копий в `content/backups/`).
Новые блоки и дизайн через админку не меняются, это работа разработчика.

Защита: вход по паролю, 5 неверных попыток подряд дают паузу 10 минут, копии и пароль закрыты от просмотра
(файлы `.htaccess` работают на хостингах с Apache, например Beget, Timeweb, REG.RU).
